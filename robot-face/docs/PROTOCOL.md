# RF-01 串口协议 v1

主机（浏览器控制台 `app/face.html`）与下位机（ESP32 + PCA9685）之间的通信约定。
两端的实现都以本文件和 `spec/rig.json` 为准。

## 物理层

- USB 串口，115200 8N1。
- 纯 ASCII 文本，一行一条命令，以 `\n` 结尾（`\r` 忽略），单行最长 160 字节。
- 可选校验：行尾加 `*HH`，`HH` 是 `*` 之前所有字节按位异或的两位大写十六进制（与 NMEA 相同）。
  带了 `*HH` 就必须校验通过，否则丢弃该行并回 `ERR 1`。主机始终带校验。

## 主机 → 下位机

| 命令 | 含义 | 回复 |
|---|---|---|
| `?` | 握手 | `RF1 fw=<版本> ch=16 hz=50` |
| `P <us0> <us1> … <usN-1>` | 设置前 N 路（N ≤ 16）的目标脉宽，单位微秒。`0` 表示该路停止输出（舵机松开）。未给出的通道保持不变 | 无（高频命令，不回复） |
| `L <ch> <min> <max>` | 设置第 `ch` 路的硬限位并写入闪存。要求 500 ≤ min < max ≤ 2500 | `OK` |
| `L?` | 读出全部限位 | 16 行 `L <ch> <min> <max>`，然后 `OK` |
| `V <us_per_s>` | 下位机侧的最大变化速度（微秒/秒），`0` 关闭。写入闪存 | `OK` |
| `T <ms>` | 看门狗超时，`0` 关闭。写入闪存 | `OK` |
| `R` | 立即松开全部舵机 | `OK` |

## 下位机 → 主机

- `OK`：命令已执行。
- `ERR <code> <说明>`：`1` 校验错误，`2` 格式错误，`3` 数值越界，`4` 未知命令。
- `P` 命令成功时不回复，失败时回 `ERR`。

## 安全行为（下位机必须实现）

1. **限位钳制**：`P` 的每个非零值先钳制到该通道的 `[min, max]` 再输出。出厂默认限位 900–2100。
   主机算错也不会把连杆顶死。
2. **看门狗**：超过 `T` 毫秒（默认 1000）没有收到合法的 `P`，松开全部舵机。
   主机崩溃或拔线后舵机不会一直顶着发热。
3. **上电不动作**：上电后所有通道不输出，直到收到第一条合法的 `P`。
4. **速度限制**：`V` 非零时，每路输出按该速度逼近目标（默认 0，由主机负责平滑）。
   通道从松开状态恢复时直接跳到目标值。

## 示例

```
> ?*3F
< RF1 fw=0.1.0 ch=16 hz=50
> L 7 1450 1950*56
< OK
> P 1500 1500 1500 1500 1500 1500 1500 1500 1500 1500 1500 1500*50
```
